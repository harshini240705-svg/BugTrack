
# BugTrack - Bug Tracking System

## About the Project
BugTrack is a simple web-based Bug Tracking System developed using Python and Flask.

It allows users to report software bugs, assign priorities, and track their status through a dashboard.

## Features
- Report new bugs
- Add bug descriptions
- Set bug priorities
- Track bug status
- View reported bugs through a dashboard

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- Bootstrap (if used in the project)

## Installation and Setup

### 1. Clone the repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project folder
```bash
cd BugTrack
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the application
```bash
python app.py
```

### 5. Open in browser
```text
http://127.0.0.1:5000
```
